# Panes
{split above|split left}: split above / left
{pane left|pane below|pane above|pane right}: pane left / below / above / right
{next pane, or [count] pane|previous pane|last focused pane}: next / previous / last pane
{close pane|close other panes}: close pane / close others
{taller|shorter|narrower|wider}: taller / shorter / narrower / wider
{resize pane left|resize pane right|resize pane up|resize pane down}: enter RESIZE; move divider left / right / up / down
RESIZE: repeat h/j/k/l; <Esc> exits
{tallest|widest|equal sizes}: tallest / widest / equal
{move pane to far left|move pane to bottom|move pane to top|move pane to far right}: move to far left / bottom / top / right
{swap with sibling pane|move pane to a new tab}: swap with sibling / move to new tab
{rotate panes forward|rotate panes backward}: rotate panes forward / backward
{new pane with recent documents}: new pane listing recent documents

# Tabs

{previous tab}: previous tab
:e :tabe :tabnew :split :vsplit <file>: reuse open view first
