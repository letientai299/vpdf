# Legend
N: Normal mode (viewport)
C: Cursor mode (glyph)
V: Visual mode (selection)
C/V: Cursor or Visual mode
P: focused panel
<C-x>: Ctrl + x
<M-x>: Alt / Option + x
<S-x>: Shift + x
<CR>: Enter
[count]: optional repeat count
:cmd <arg>: required argument
:cmd [arg]: optional argument

# Modes
NORMAL: viewport navigation
CURSOR: glyph navigation
VISUAL / V-LINE: character / line selection
YANK: pending copy operator; motion or object completes it
REGION: rectangle editing; <CR> opens actions; <Esc> cancels
ACTIONS: capture actions; R returns to rectangle editing
PROMPT: command, search, or password entry
HINT: link label selection
MENU: context actions
PEEK: keyboard link preview
PAGES: page overview
Panel title: keys act on the focused list
Temporary interactions preserve the underlying reading mode
Text / page: presentation choice, same reading modes

# Performance
:perf [on|off]: toggle global top stats; saved across restarts
Stats refresh every 100 ms, 1 s when idle; M = MiB, K/s = KiB/s
FPS: content frames flushed/s, rolling 1s; idle reaches zero
CPU: process CPU, rolling 1s; 100% = one core; excludes helpers
RSS: process resident memory; excludes terminal and helpers
Out: session terminal output, excluding stats, rolling 1s
UI FPS does not measure monitor presentation
Stats-only paints do not count as content frames
Sampling adds work; CPU 0.0% is rounded, not zero execution
