# Vpdf v0.1.0

Vpdf is a Vim-inspired PDF reader for the terminal, powered by MuPDF and the
Kitty graphics protocol.

- Navigate with Vim-style keys, outlines, links, marks, and history.
- Search, select and copy text, and recognize scans with optional OCR.
- Read across tabs and split panes; capture figures and export images.
- Keep reading positions without changing source PDFs.

This release distributes the terminal reader. The native macOS app remains
source-only.

See [GitHub][github] for installation, terminal requirements, and full
documentation.

[github]: https://github.com/letientai299/vpdf/blob/main/docs/readme.md
