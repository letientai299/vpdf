# Legend
N: Normal mode (viewport)
C: Cursor mode (glyph)
V: Visual mode (selection)
C/V: Cursor or Visual mode
P: focused panel
<C-x>: Ctrl + x
<M-x>: Alt / Option + x
<S-x>: Shift + x
<CR>: Enter
[count]: optional repeat count
:cmd <arg>: required argument
:cmd [arg]: optional argument

# Move

i: enter C at visible text
C/V h j k l: glyph motions
C/V w b e: word motions
C/V W B E gE: WORD motions

C/V 0 ^ $: line motions
C/V { }: previous / next paragraph
[count]gg G: page jump
:<n|label>: jump to a page number or label

Jumps: flash landing line for 600 ms

ma mA: mark here / across documents
'a `a: go to mark line / position

# Scroll and zoom

+ - =: zoom in / out / fit width
zf: fit page
zF: fit selected figure; reserve action bar

Hover citation: status quotes the cited reference

Hover panel row: underline; status shows clipped title

Printed URLs, DOIs, mail addresses: act as links

# Performance
:perf [on|off]: toggle global top stats; saved across restarts
Stats refresh every 100 ms; M = MiB, K/s = KiB/s
FPS: content frames flushed/s, rolling 1s; idle reaches zero
CPU: process CPU delta; 100% = one core; excludes helpers
RSS: process resident memory; excludes terminal and helpers
Out: session terminal output, including stats, rolling 1s
UI FPS does not measure monitor presentation
Stats-only paints do not count as content frames
Sampling adds work; CPU 0.0% is rounded, not zero execution
