# Legend
N: Normal mode (viewport)
C: Cursor mode (glyph)
V: Visual mode (selection)
C/V: Cursor or Visual mode
P: focused panel
<C-x>: Ctrl + x
<M-x>: Alt / Option + x
<S-x>: Shift + x
<CR>: Enter
[count]: optional repeat count
:cmd <arg>: required argument
:cmd [arg]: optional argument

# Move
h j k l / arrows: pan / scroll in N
i: enter C at visible text
Counts scale viewport and glyph motions
C/V h j k l: glyph motions
C/V w b e: word motions
C/V W B E gE: WORD motions
C/V ( ): previous / next sentence
C/V 0 ^ $: line motions
C/V { }: previous / next paragraph
[count]gg G: page jump
:<n|label>: jump to a page number or label
[count][[ ]]: previous / next heading; record jump
]i [i: next / previous figure; counts repeat
<Space><S-Space>: next / previous page
<C-o><C-i> '': jump back / forward
Jumps: flash landing line for 600 ms
ma mA: mark here / across documents
'a `a: go to mark line / position

# Scroll and zoom
<C-d><C-u>: half-screen scroll
<C-f><C-b>: full-screen scroll
<C-e><C-y>: row scroll
Scroll keys keep glyph and selection positions
zt zz zb: target at top / middle / bottom
+ - =: zoom in / out / fit width
zf: fit page
zF: fit selected figure; reserve action bar
zh zl: pan left / right
zr: rotate clockwise
zc: crop / restore page margins
Wheel: scroll the view, K preview, or note under the pointer
Page <C-wheel>: zoom; keep the point under the pointer
Page <S-wheel> / sideways wheel: pan a zoomed page or wide text

# Select and yank
v V: enter character / line V
C v/V: select from positioned glyph
N v/V: visible target, else first visible text
No text: selection unavailable; run :ocr explicitly
o: swap selection ends
gv: reselect
<Esc> / yank: return to V entry mode
C <Esc>: return to N when idle
y yy yw ye y$: yank
yy Y: join wrapped lines; rejoin hyphenated words
yY: yank lines as laid out
yp: yank full file path
"" "+ "*: system clipboard
"a "A: named register / append
Click / drag: set N target / select
Double click: select word

# Text objects
V / y + i/a: inner / around objects
C i/a: no object prefix
w W s p: word / WORD / sentence / paragraph
( ) [ ] { } < >: paired brackets
b B: parentheses / braces aliases
' ": ASCII or typographic quotes
Counts: repeat objects / enclosing bracket pairs

# Find
/ ?: search forward / backward
n N: next / previous match
*: search active glyph or visible target word
\v: regex prefix

# Figures
gF: open selected figure actions
h j k l: choose image, text, PNG, or OCR
<CR>: run action; <Esc> closes bar
Save PNG: beside document with numbered filename
OCR: needs Tesseract; copies region text
Close bar: keep mode, selection, committed jobs

gs: search results
f F: link hints / copy URLs
gl: links on this page
gp: page thumbnails
gp wheel: scroll thumbnails; keep selection
gr: recent documents
ga: annotations (read-only)
Annotations <CR>: jump, enter Cursor, and show note
Annotations K: preview selected note
P <CR>: follow row; focus content in N
P o / click: follow; keep panel focus
P / ? n N: search rows
P { }: previous / next heading
P yy: yank row
<Tab><S-Tab>: toggle content / panel focus
P q / gq: close panel
gx: focus extracted-text presentation
g? <F1>: this reference
<Esc>: cancel transient or pending input first
P wheel: scroll list; keep row selection
Panel hover: underline row; show clipped title
gp hover: show page label and section
q: close panel, tab, or reader

# Preview
K / <CR>: preview / follow visible explicit target
K: show annotation note when present
Hover note/highlight: show author, comment
j k: scroll rows
<C-d><C-u>: scroll half height
Border: destination page; arrows mark clipped edges
<CR>: follow link or dismiss note
<Esc>: cancel preview layer

# Panes
<C-w>s/v: split above / left
<C-w>h/j/k/l: pane left / below / above / right
<C-w>w/W/p: next / previous / last pane
<C-w>c/o: close pane / close others
<C-w>+/-/</>: taller / shorter / narrower / wider
<C-w>_/|/=: tallest / widest / equal
<C-w>H/J/K/L: move to far left / bottom / top / right
<C-w>x/T: swap with sibling / move to new tab
<C-w>r/R: rotate panes forward / backward
<C-w>n: new pane listing recent documents

# Tabs
P file <CR>/o: target tab / split; reuse open view
Recent <CR>/click: open in covered pane
gt [count]gt: next / nth tab
gT: previous tab
:e :tabe :tabnew :split :vsplit <file>: reuse open view first
Drop a PDF on a pane: open there; reuse view; prompt takes it
N paste of a PDF path: open it; a prompt takes the text
Pane changes: keep C/V, queries and panel focus

# Command line
<Tab><S-Tab>: list, then cycle completions
<Up><Down><C-p><C-n>: history
<C-r><C-s>: history containing the text
<C-Space><Right><End>: accept suggestion
<M-f>: accept next suggested word
<C-a><C-e><C-b><C-f>: line start / end / char
<M-b><M-f><C-Left><C-Right>: words
<C-w><M-BS><M-d>: delete word
<C-u><C-k><C-y>: kill line / to end, yank
<C-t><C-_>: transpose, undo
<C-x><C-e>: edit in $EDITOR
