# Move
h j k l: glyph motions
w b e: word motions
0 ^ $: line motions
{ }: previous / next paragraph
[count]gg G: page jump
Space Shift-Space: next / previous page
Ctrl-o Ctrl-i '': jump back / forward
ma mA: mark here / across documents
'a `a: go to mark line / position

# Scroll and zoom
Ctrl-d Ctrl-u: half-screen scroll
Ctrl-f Ctrl-b: full-screen scroll
Ctrl-e Ctrl-y: row scroll
zt zz zb: cursor at top / middle / bottom
+ - =: zoom in / out / fit width
zf: fit page
zh zl: pan left / right
zr: rotate clockwise
zc: crop / restore page margins

# Select and yank
v V: character / line selection
o: swap selection ends
gv: reselect
y yy yw ye y$: yank
viw vaw yiw yaw: word objects
"" "+ "*: system clipboard
"a "A: named register / append
Click / drag: move / select
Double click: select word

# Find
/ ?: search forward / backward
n N: next / previous match
*: search cursor word
\v: regex prefix

# Panels
go: table of contents
gs: search results
f: link hints; F copies URLs
K: preview link target; Enter follows
gl: links on this page
gp: page thumbnails
gr: recent documents
:jumps: recorded jump destinations
ga: annotations (read-only)
Enter: follow link or row
o: follow, keep panel focus
/ ? n N: search rows of a focused panel
{ }: previous / next heading in a panel
yy: yank the panel row
gq: close panel
gx: text preview
g? F1: this reference
Esc: cancel / unfocus panel
Click / wheel in panel: follow / move
q: close panel, tab, or reader

# Panes
Ctrl-w s Ctrl-w v: split above / left
Ctrl-w h j k l: pane left / below / above / right
Ctrl-w w W p: next / previous / last pane
Ctrl-w c o: close pane / close others
Ctrl-w + - < >: taller / shorter / narrower / wider
Ctrl-w _ | =: tallest / widest / equal
Ctrl-w H J K L: move pane to far left / bottom / top / right
Ctrl-w x T: swap with sibling / move to new tab
Ctrl-w r R: rotate panes forward / backward
Ctrl-w n: new pane listing recent documents

# Tabs
gt [count]gt: next / nth tab
gT: previous tab
:e :tabe: open here / in a new tab

# Command line
Tab Shift-Tab: list, then cycle completions
Up Down Ctrl-p Ctrl-n: history
Ctrl-r Ctrl-s: history containing the text
Ctrl-Space Right End: accept suggestion
Alt-f: accept next suggested word
Ctrl-a Ctrl-e Ctrl-b Ctrl-f: line start / end / char
Alt-b Alt-f Ctrl-Left Ctrl-Right: words
Ctrl-w Alt-Backspace Alt-d: delete word
Ctrl-u Ctrl-k Ctrl-y: kill line / to end, yank
Ctrl-t Ctrl-_: transpose, undo
Ctrl-x Ctrl-e: edit in $EDITOR
